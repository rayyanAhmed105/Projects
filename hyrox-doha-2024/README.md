
# HYROX Doha 2024: Web Data Collection & Exploratory Data Analysis

This project analyzes participant performance and event dynamics from HYROX Doha 2024 using web-collected data and exploratory data analysis techniques.

The analysis focuses on participation trends, gender distribution, and performance variability across race stages to generate insights from real-world event data.
## Article
Full write-up available here:  
https://medium.com/@RayyanElfadel/hyrox-doha-2024-data-insights-gender-inclusion-toughest-hyrox-stations-29dddf077fe6

## Key Insights
- Diverse international participation across multiple nationalities  
- Balanced gender representation with strong female participation  
- Significant variability across race stages, highlighting key performance bottlenecks  

## Figures
The figures in this repository reproduce the analysis presented in the article, including:
- Participant nationality distribution  
- Gender participation breakdown  
- Stage-level performance distributions  
- Comparison of median participants and top performers
